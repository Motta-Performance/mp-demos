# mp-demos

Repositório de demonstrações e sites de clientes para deploys na Vercel.

Estrutura esperada:

- projetos/<nome-do-projeto>/
  - index.html            # arquivo de entrada para deploy na Vercel (padrão)
  - <nome-do-projeto>.html
  - imagens/              # imagens do projeto
  - README.md             # instruções específicas do projeto

Instruções rápidas

1. Para adicionar um novo projeto, crie uma pasta em `projetos/` com o nome do projeto e inclua um `index.html`.
2. Para deploy na Vercel selecione o repositório e, ao configurar o projeto, ajuste "Root Directory" para `projetos/<nome-do-projeto>`.
3. Para contribuir via branch: crie um branch com prefixo `add/` ou `feature/`, faça o PR e depois faça merge no branch principal.
